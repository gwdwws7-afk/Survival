## A. Overview

**Day-Night Cycle 是 Ravensong 的"反向呼吸"——太阳是敌人，月亮是盟友。** 这是 Ravensong 与所有其他生存建造游戏**最根本的机制差异**。传统生存是"白天种田晚上守家"，Ravensong 是"白天苟且晚上拼命"。

一个完整的游戏日 = **12 小时白天 + 12 小时黑夜**（游戏内时间），对应真实时间约 **6 + 6 = 12 分钟**（可调）。玩家的所有能力（移速/视野/编织效率/战斗伤害）都随时间剧烈变化，这种**强反差**让"什么时候做什么"成为核心决策。

叙事根因：玩家是被奥丁放逐的女武神，**阿斯加德的光**对她来说不再是祝福，而是灼烧与监控；唯有月光（米德加尔特之夜）才让她恢复神性。

## B. Player Fantasy

### 主幻想
> "我是月之女，不是日之子。日出我退，日落我进。"

### 关键体验时刻
- **黄昏前 60 秒**：屏幕角落亮起**暮色警告**——这是 Ravensong 最"上瘾"的设计点之一。玩家必须决定：再战一波 vs 冲回聚落
- **日出前 60 秒**：**晨光警告**——如果你还在外面，**奥丁之眼**会扫过来
- **夜半**：月光满盈，**编织速度翻倍**，聚落灯火通明，英灵们开始活跃工作

### 玩家情绪轨迹（一局循环）
```
黄昏警告 → 紧张（要不要再战？）→ 决定撤离
                                       ↓
返家途中 → 兴奋（满载猎物和新兵）
                                       ↓
聚落篝火 → 安宁（看英灵围坐）
                                       ↓
深夜 → 强能感（月光下做任何事都快）
                                       ↓
日出警告 → 警觉（开始新一天的规划）
                                       ↓
白天躲藏 → 压抑（慢、视野窄、阴影视角）
                                       ↓
黄昏警告 → 循环重启
```

**这是 Ravensong 的"心跳"**——一快一慢、一紧一松，让玩家在 1-2 小时 session 内自然形成"期待夜晚"的肌肉记忆。

## C. Detailed Design

### C.1 核心规则（Core Rules）

#### 规则 1：时间单位是"游戏内小时"，不是真实时间
- 1 游戏内小时 = `GameConfigSO.realSecondsPerGameHour` 真实秒（默认 30 秒）
- 24 游戏内小时 = 12 真实分钟（默认）
- UI 永远显示**游戏内时间**（"06:00", "18:00"）+ 真实剩余时间（如 "现实 3:42 剩余"）

#### 规则 2：所有玩家能力都是时间相关
- 移速、视野、编织时间、战斗伤害，**全部**由 `currentTimeOfDay` 驱动
- 没有任何"无视时间"的玩家能力
- 唯一例外：进入庇护所后，时间效果减弱（见 C.7）

#### 规则 3：状态分三种
- **Day**：06:00 - 18:00（白天 12 游戏小时）
- **Night**：18:00 - 次日 06:00（夜晚 12 游戏小时）
- **Transition**：Dawn（05:00-06:00）/ Dusk（17:00-18:00），1 游戏小时各

#### 规则 4：世界时间对所有实体一致
- 玩家、英灵、敌人、NPC、动物，**全部按同一个全局时钟**
- 不存在"个人时间"或"局部时间"

#### 规则 5：特定场景时间暂停
- boss 战、关键对话、菜单暂停——**时间不流逝**，避免玩家在结算动画里被"天亮灼伤"等荒谬情况

### C.2 Day 状态（白天 = 06:00 - 18:00）

**这是 Ravensong 的"压迫相"**——玩家能力被全面压制。

| 维度 | 白天值 | 相对基线 |
|---|---|---|
| 移速 | 50% 基线 | **-50%** |
| 视野 | 50% 基线 | **-50%** |
| 编织时间 | 150% | **+50% 时间（更慢）** |
| 战斗伤害 | 75% | **-25%** |
| 被动神力余烬 | 0.5/小时 | 弱产出 |
| 织出物品返还 | 20% | 弱奖励 |
| 敌人巡逻密度 | 高 | 危险 |
| 敌人警觉范围 | +30% | 易被发现 |
| 奥丁之眼扫描 | **是** | 强制躲避 |

**视觉**：
- 头顶强光 + 角色身上有"晒伤"感（苍白偏色）
- 视野短，画面边缘有强光晕（"被白光照瞎"）
- 远景雾化严重
- 配色偏冷淡（白灰 + 暗影）

**音频**：
- BGM 紧张、低沉、稀疏
- 风声 + 偶尔乌鸦叫
- 没有音乐主题展开

**AI 行为**：
- 敌人更激进（白天它们"占上风"）
- 英灵回聚落休息，工作效率 -80%
- 玩家**应**在白天回聚落休整、计划、整理物品

### C.3 Night 状态（夜晚 = 18:00 - 06:00）

**这是 Ravensong 的"释放相"**——玩家恢复全部神性，掌控世界。

| 维度 | 夜晚值 | 相对基线 |
|---|---|---|
| 移速 | 160% 基线 | **+60%** |
| 视野 | 160% 基线 | **+60%** |
| 编织时间 | 50% | **-50% 时间（更快）** |
| 战斗伤害 | 120% | **+20%** |
| 被动神力余烬 | 1.5/小时 | 强产出 |
| 织出物品返还 | 40% | 强奖励 |
| 敌人巡逻密度 | 中 | 较少 |
| 敌人警觉范围 | 基线 | 正常 |
| 月相词缀激活 | **是** | 见 §C.6 |

**视觉**：
- 月光清冷（cyan + 深蓝主导）
- 角色身上"神性"感（边缘 cyan 辉光）
- 视野开阔，能看很远
- 远景清晰，星星可见
- 配色偏冷调（深蓝 + cyan + 暖金点缀）

**音频**：
- BGM 史诗、丰富、有主题
- 渡鸦低鸣 + 远处篝火
- 月相变化时音乐层变化

**AI 行为**：
- 敌人巡逻减少
- 英灵活跃工作，效率 +50%
- 玩家**应**在夜晚出击、采集、招募、战斗

### C.4 转换机制（Dawn & Dusk）⭐ 关键体验

**这是 Ravensong 的"心跳跳变"**——不是硬切，是有节奏的过渡。

#### Dawn（05:00 → 06:00）
1. **05:00**：触发**晨光警告**（屏幕顶部暖光渐显 + 乌鸦盘旋 + 1 声低鸣）
2. **05:00-05:30**：30 游戏分钟**"暮光带"**——介于夜与日之间，所有数值线性插值
3. **05:30**：**最后撤离窗口**——视野/移速开始接近日间值，但仍可用
4. **05:30-06:00**：**黎明强制**——日间值全开，视野急剧收缩
5. **06:00**：**日出**——`DayTimeStarted` 事件触发

#### Dusk（17:00 → 18:00）
1. **17:00**：触发**暮色警告**（屏幕边缘暖色消退 + 远处篝火声 + 1 声悠长号角）
2. **17:00-17:30**：30 游戏分钟**"金时刻"**——所有数值仍为日间，但视觉上开始"松弛"
3. **17:30**：日间值仍持续，但**敌人撤退开始**——你可以开始向外探索
4. **17:30-18:00**：**暮光强制**——夜间值开始接管
5. **18:00**：**日落**——`NightTimeStarted` 事件触发

#### 视觉表现（转换期间）
- 屏幕边缘 vignette 颜色：从 cyan（夜）→ 橙红（暮）→ 白（昼）→ 反向
- 主角脚下的"光圈"颜色同步
- 远景雾色变化
- 持续 30-60 真实秒，玩家有明确"窗口感"

#### 数值插值公式
```
t = (currentTime - transitionStart) / transitionDurationGameHours
mult = lerp(dayMult, nightMult, smoothstep(0, 1, t))
```
- 不用 linear（太机械）
- 不用 ease-in-out（太柔）
- **smoothstep** 给"先慢后快"的感觉，符合"日出骤然"的体验

### C.5 奥丁之眼（Day 专属威胁事件）

**奥丁之眼 = 白天最高威胁**。叙事上对应"奥丁在监视堕落的女儿"，机制上是**强制躲避事件**。

#### 触发条件
- 仅白天（Dawn 之后）
- 玩家**不在庇护所**时
- 每 30 游戏分钟（0.5 小时）有 1 次判定
- 判定成功率 30%（即平均 1.5 游戏小时 = 75 真实秒一次扫描）

#### 流程
1. **预警（3 真实秒）**：屏幕顶部出现**金色光柱扫描**从远到近，乌鸦惊飞
2. **扫描（5 真实秒）**：金色光柱覆盖玩家**当前所在网格**
3. **结果**：
   - 在庇护所/树荫/建筑阴影下 → 躲过，无事发生
   - 暴露在光柱中 → **强制战斗**触发（中等强度敌人 2-4 个）

#### 视觉
- 金色光柱从天而降，**只覆盖约 8x8 网格**
- 玩家有 3 秒反应时间跑向阴影
- 这是"白天躲藏"玩法的核心压力

#### 平衡
- 30% 概率 = 平均 1.5 游戏小时 1 次 = 白天 12 小时有约 8 次扫描
- 触发 8 次里有 2-3 次会真正遇到（30% × 8 = 2.4 次）
- 玩家白天有强烈动机回聚落（聚落是安全区）

### C.6 月光赋能（Night 专属增益）

**月相系统**：每个游戏月（30 游戏日 = 360 游戏小时 = 180 真实分钟）有 8 个相位循环。

| 月相 | 周期 | 词缀 |
|---|---|---|
| 🌑 新月 | 1/8 | 无词缀，但视野 +20%（最暗） |
| 🌒 蛾眉月 | 1/8 | "沉默"：敌人警觉 -20% |
| 🌓 上弦月 | 1/8 | "洞察"：可看见隐藏资源 |
| 🌔 盈月 | 1/8 | "幸运"：掉落 +20% |
| 🌕 满月 | 1/8 | **"神显"**：编织出传说物品概率 +50% |
| 🌖 亏月 | 1/8 | "沉默"：敌人警觉 -20% |
| 🌗 下弦月 | 1/8 | "洞察"：可看见隐藏资源 |
| 🌘 残月 | 1/8 | "幸运"：掉落 +20% |

**循环周期**：8 真实游戏日 = 8 × 12 真实分钟 = 96 真实分钟（约 1.6 小时真实玩一次完整月相）—— 这是合理的循环长度。

### C.7 庇护所系统（白天生存）

**庇护所 = 白天的"安全区"**——但**不是免费的**。

| 庇护所类型 | 减白天效果 | 限制 |
|---|---|---|
| **聚落内部** | 完全屏蔽日间效果（移速 100%） | 必须回家 |
| **建筑阴影** | 视野 -25% 而非 -50%，但仍暴露 | 部分保护 |
| **大树阴影** | 视野 -25% 而非 -50% | 移动需重新找 |
| **小洞穴/凹陷** | 完全屏蔽 | 罕见，特定位置 |

**关键设计**：聚落是"唯一完美庇护所"——这强化了**回聚落**的动机，与"Living Hearth"支柱完美契合。

### C.8 时间暂停（特定场景）

以下场景**时间停止流逝**：
- 进入 boss 战（用 boss 自己的"内在时间"，避免日升打断）
- 关键对话播放中
- 菜单/暂停界面打开
- 死亡画面/重生画面

退出暂停时，时间恢复正常流速。

### C.9 与其他系统的交互

| 系统 | Day-Night 怎么影响它 |
|---|---|
| **Fate-Thread** | 编织时间 × Day-Night 系数（白天 1.5x、夜间 0.5x） |
| **Combat** | 玩家伤害 × Day-Night 系数；敌人 AI 行为切换 |
| **Gathering** | 白天采集效率 -30%，夜间 +50%（与游戏概念 §3.2 一致） |
| **Inventory** | 不影响（物品不分日夜） |
| **Einherjar** | 白天休息效率 -80%，夜间工作 +50% |
| **Death & Send-off** | 死亡可发生在任意时间；复活在下次日出时 |
| **Settlement** | 聚落"灯火"在夜间亮起（视觉），白天暗淡 |
| **World Exploration** | 奥丁之眼仅白天；月相词缀仅夜间 |
| **Quest-Event** | 部分事件锁定为白天/夜间触发 |
| **UI/HUD** | HUD 时钟显示当前时间 + 距下次转换剩余时间 |
| **Save** | 时间持久化（详见 Save GDD） |
| **Combat (敌人警觉可视化)** | 敌人脚下光圈颜色/范围随 Day-Night 变化（见 §C.10） |

### C.10 敌人警觉范围可视化（决策 #5 锁定：MVP 立即加）⭐

**目的**：让玩家**看见**敌人的警觉范围，从而在白天更聪明地规划路径，夜间利用"沉默"词缀的优势。

**视觉表现**：
- 每个敌人在脚下有一个**半透明圆形光圈**，光圈大小 = 警觉范围
- 光圈颜色：
  - **白天**：暗红色（`#CC4444` alpha 30%）—— 警告
  - **夜间**：暗绿色（`#44CC66` alpha 20%）—— 安全
  - 蛾眉月/亏月"沉默"词缀时：暗青色（`#4488CC` alpha 20%）
- 光圈脉动：1 Hz 慢呼吸，提示"激活"
- 玩家进入光圈时：光圈变亮（alpha 60%），表示"被发现了"

**与 day/night 互动**：
- 敌人 `alertRange` 基础值 = `GameConfigSO.enemyAlertRangeBase`（默认 5 网格）
- 白天 `alertRange × GameConfigSO.enemyAlertRangeDayMultiplier`（默认 × 1.3，与 §C.2 day state +30% 一致）
- 夜间 `alertRange × 1.0`
- "沉默"词缀：`alertRange × 0.8`

**技术实现**：
- 每个敌人 GameObject 有 child SpriteRenderer + 自定义 shader
- shader 接收：当前 alertRange（每帧从 GameConfig + TimeManager 计算）
- shader 输出：圆环/光圈 + 脉动
- 性能预算：每个敌人 ~0.05ms 渲染开销，**用 GPU Instancing 优化**（避免 100 个敌人 × draw call）

**调参开关**：
- `GameConfigSO.showEnemyAlertRange = true`（MVP 默认开，玩家可关）
- `GameConfigSO.enemyAlertRangeBase = 5f`
- `GameConfigSO.enemyAlertRangeDayMultiplier = 1.3f`

**为什么这是设计支柱的具体化**：
- **Waxing Moon**：玩家**看见**光圈颜色从红（白天的危险）变绿（夜间的安全），把"日夜反转"做成了**视觉证据**而不是文字描述
- **Woven Power**：玩家可以利用光圈规划编织时机（比如"在敌人光圈外编织"）
- **Living Hearth**：玩家甚至可以观察"英灵是否警觉范围太大"来评估聚落氛围

### F.1 时间相关基础公式

```csharp
// 玩家当前各系数（由 currentTimeOfDay 驱动）
float speedMult = GetSpeedMult(currentTime);     // 0.5 ~ 1.6
float visionMult = GetVisionMult(currentTime);   // 0.5 ~ 1.6
float weavingTimeMult = GetWeavingTimeMult(currentTime);  // 0.5 ~ 1.5
float combatDamageMult = GetCombatDamageMult(currentTime); // 0.75 ~ 1.2
```

### F.2 状态判断

```csharp
enum TimeState { Dawn, Day, Dusk, Night }

TimeState GetTimeState(float currentTime) {
  float hour = currentTime % 24f;
  if (hour >= 5f && hour < 6f) return TimeState.Dawn;
  if (hour >= 6f && hour < 17f) return TimeState.Day;
  if (hour >= 17f && hour < 18f) return TimeState.Dusk;
  return TimeState.Night;
}
```

### F.3 系数插值（转换期间）

```csharp
float LerpMult(float hour, float dayMult, float nightMult) {
  // Dawn: 05:00 → 06:00，从 nightMult 插值到 dayMult
  // Dusk: 17:00 → 18:00，从 dayMult 插值到 nightMult
  
  float t;
  if (hour >= 5f && hour < 6f) {
    // Dawn: 1.0 at 05:00 → 0.0 at 06:00
    t = 1f - (hour - 5f);
  } else if (hour >= 17f && hour < 18f) {
    // Dusk: 0.0 at 17:00 → 1.0 at 18:00
    t = hour - 17f;
  } else {
    return hour >= 6f && hour < 17f ? dayMult : nightMult;
  }
  
  float smoothT = t * t * (3f - 2f * t);  // smoothstep
  return Mathf.Lerp(dayMult, nightMult, smoothT);
}
```

### F.4 月相计算

```csharp
MoonPhase GetMoonPhase(float totalGameHours) {
  // 8 相位循环
  // 1 完整循环 = 8 游戏日 = 192 游戏小时
  const float FULL_CYCLE = 192f;
  float phaseFloat = (totalGameHours / FULL_CYCLE) * 8f;
  return (MoonPhase)((int)phaseFloat % 8);
}
```

### F.5 奥丁之眼扫描判定

```csharp
// 每 0.5 游戏小时 = 15 真实秒 判定一次
bool ShouldSpawnOdinEye(float timeSinceLastScan) {
```

### F.6 庇护所效果

```csharp
float GetShelterReduction(ShelterType type) {
  switch (type) {
    case ShelterType.Settlement: return 1.0f;    // 完全屏蔽
    case ShelterType.BuildingShadow: return 0.5f;  // 屏蔽一半
    case ShelterType.TreeShadow: return 0.5f;
    case ShelterType.None: return 0f;
  }
}

// 应用到玩家能力
float effectiveVision = baseVision * (1f - GetShelterReduction(shelter)) 
                          + baseVision * GetShelterReduction(shelter) * dayVisionMult;
```

## E. Edge Cases


### E.0 中后期压力曲线（游戏阶段压力分布）⭐ 修复 P1 缺口

> 按 Survival-Crafting 框架的"中后期是否还存在真实压力"检查项显式定义 Ravensong 的 5 阶段压力。

#### 5 阶段压力曲线

| 阶段 | 天数 | 主要压力 | 玩家目标 | "无事可做"风险 |
|---|---|---|---|---|
| **新手期** | Day 1-30 | 基础生存（白天弱/夜晚强）+ 资源贫瘠 + 学习编织 | 招募 1-3 英灵 + 完成誓言 1.x | 🟢 无 |

### 决策之间的协同

- **#1 + #5**：HP 不损失，但**敌人光圈颜色从红（白天的危险）变绿（夜间的安全）**——把"日夜反转"做成了**视觉证据**，比文字描述直观 10 倍。
- **#2 + #3**：奥丁之眼（白天威胁）和月相词缀（夜间增益）构成**对称压力**——白天被迫躲藏，夜间主动出击。

- **#5 是 Waxing Moon 支柱的具体化**：玩家不需要"知道"日夜反转，**他们会看见**——从红色光圈到绿色光圈，从"快被追"到"主导世界"。

### 渲染层
- **Unity 2D Lights** —— 全局光照颜色（白天 0.95 偏白 / 夜间 0.5 偏冷 cyan）
- **Post-processing Volume** —— 白天饱和度 0.8 / 夜间 0.6 + bloom
- **Skybox** —— 6 个天空盒（dawn / day / dusk / night / full_moon / new_moon）
- **VFX** —— 晨光警告的金色光柱；月光的 cyan 光晕

### 性能预算
- 时间更新：每帧一次（0.01ms）
- 状态判断：O(1) 一次比较
- 奥丁之眼扫描判定：每 0.5 游戏小时一次
- 月相计算：每游戏日 1 次
