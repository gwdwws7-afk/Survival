## A. Overview

**UI / HUD 是 Ravensong 的"门面"——所有签名系统的玩家接触点都在这里。** 不是创造"新的游戏体验"，而是**让已经设计好的游戏体验"被看到、被操作、被记住"**。

Ravensong 的 UI 设计哲学是 **"叙事性 UI"（Narrative UI）**：UI 本身**不**喧宾夺主，而是**作为叙事画面的延伸**——半透明深色画布 + 油画质感边框 + 卢恩符文作为装饰 + 字体克制（少字大字）。**风格统一锚定到 `style-bible.md` 的深色油画风**：navy + cyan + 金色，与英灵殿光柱、奥丁之眼、编织丝线视觉一致。

UI 框架覆盖 9 类界面：
- **HUD**（常驻）——血量 / Stamina / God-Ember / 时间 / 工具栏 / 罗盘
- **弹窗**（Modal）——死亡选择 / 编织 / 招募 / 任务 / Boss 战
- **菜单**（Menu）——物品栏 / 装备 / 聚落 / 誓言 / 英灵 / 设置 / 暂停
- **Toast**（通知）——资源获取 / 等级提升 / 提示
- **对话**（Dialogue）——NPC 说话（与 `DialogueSO` 协同）
- **状态栏**（Status Bar）——英灵 / 聚落 / 任务进度
- **罗盘**（Compass）——方向 + 兴趣点标记
- **教程**（Tutorial）——首次提示（v1.0 简化：30 条左右）
- **Loading / Title**——载入画面 + 主菜单

**MVP 范围**：5 天工作量（systems-index 已锁定）。**不做**：花哨的过场动画、复杂的多层菜单、皮肤系统、玩家定制主题（v1.1 决策）。

数据层由**新增**的 `UIStyleSO`（data-config.md C.2 类型 11）驱动；本 GDD 专注于**HUD 设计、弹窗模式、菜单架构、教程机制、性能预算、风格统一**。

## C. Detailed Design

### C.1 核心规则（Core Rules）

#### 规则 1：UI 是叙事的延伸，不是"另一个屏幕"
- 所有界面**统一**深色画布 + 卢恩符文边框
- **不**用纯黑/纯白——总带 5% 油画纹理
- 字体限制为 1-2 个衬线体（参考 Ravensong 风格）

#### 规则 2：UI 分 3 层（深度感）
- **底层（HUD）**：常驻屏幕角落，**不**抢戏
- **中层（弹窗 / 菜单）**：覆盖 30-60% 屏幕，模态
- **顶层（紧急）**：覆盖 90% 屏幕，强制回应（如死亡选择）

#### 规则 3：所有 UI 元素 0.5 秒淡入
- 不**用**滑动/旋转等花哨动画
- 0.5 秒 = "有出现感"但不打扰

#### 规则 4：UI 不阻塞游戏（除 Modal）
- HUD 永远**不**阻塞
- Toast 永远**不**阻塞
- 弹窗（Modal）暂停游戏（除特定战斗 UI）
- 菜单（按 Esc）暂停游戏

#### 规则 5：UI 主题自动跟随 Day-Night
- 白天 HUD = 偏暖（米黄/淡金）
- 夜晚 HUD = 偏冷（深蓝/青）
- Dawn/Dusk = 插值
- 玩家**不**可手动切换主题（v1.0 决策：避免"白天模式党" vs "夜晚模式党" 争论）

#### 规则 6：所有 UI 有声音反馈
- 按钮悬停 = 轻 "ding"
- 按钮点击 = 中 "叮"
- 弹窗打开 = 低沉 "咚"
- 弹窗关闭 = 反向 "咚"
- 玩家**可**在设置关闭 UI 音

#### 规则 7：UI 性能预算 16ms / 帧
- HUD：< 4ms
- 弹窗/菜单：< 8ms
- 全部 UI 总和：< 16ms（60 FPS 预算）

#### 规则 8：UI 支持键盘 + 手柄 + 鼠标
- 全键盘映射（参考 input-system.md）
- 全手柄映射
- 鼠标：仅菜单/物品栏使用（战斗用键鼠/手柄）

### C.2 HUD（常驻显示）⭐

#### HUD 元素布局（2D 俯视游戏）

```
+--------------------------------------+
| [罗盘]                       [时间]  |  ← 顶部
|                                      |
|                                      |
|           [游戏画面]                  |
|                                      |
|                                      |
|                                      |
| [血量条] [Stamina条]      [工具栏 1-4]|  ← 底部
| [God-Ember 图标 + 数字]              |
+--------------------------------------+
```

#### 元素 1：血量条（左下）
- 长度：200px
- 高度：16px
- 颜色：深红渐变到金（血量低时闪烁）
- 显示：当前 / 最大（如 `100/100`）
- 玩家受伤时**短暂**抖动屏幕（0.2s）

#### 元素 2：Stamina 条（左下，血量条下方）
- 长度：200px（与血量条等长）
- 高度：8px
- 颜色：cyan 渐变
- 隐藏条件：Stamina 满时**不**显示（节省空间）
- 战斗/奔跑时**显示**

#### 元素 3：God-Ember（左下第三行）
- 图标：奥丁之眼（小，32×32）
- 数字：当前 god-ember 量（如 `42`）
- 拾取时数字 +N 飞入（粒子效果）
- 满 999 时图标变金

#### 元素 4：时间（右上）
- 显示：游戏内时间（如 `Day 5 - 14:30`）
- 图标：太阳（白）/月亮（夜）随 Day-Night 切换
- 点击 → 打开日历 / 历史

#### 元素 5：罗盘（顶部居中）
- 横向 360° 罗盘
- 显示：兴趣点方向（boss / 聚落 / 任务）
- 颜色：cyan（兴趣点） / 金（主线任务） / 灰（已访问）
- 距离>200m 时**不**显示（避免 UI 过载）

#### 元素 6：工具栏（右下）
- 4 个槽位（决策 #6 from input-system 已锁定）
- 显示：物品图标 + 快捷键数字（1-4）
- 选中态：cyan 边框
- 切换：键盘 1-4 / 手柄 LB/RB

#### 元素 7：死亡选择 / 任务进度（顶部居中，条件显示）
- 死亡选择：5 选 1 按钮横排
- 任务进度：`2/5 英灵已送走`
- 自动消失：5 秒无操作

### C.3 弹窗（Modal Dialogs）

#### 弹窗分类

| 类型 | 触发 | 阻塞游戏 | 示例 |
|---|---|---|---|
| **死亡选择** | 英灵 dying | ✅ | 5 选 1 送别 |
| **编织弹窗** | 玩家按 W | ✅ | 选 2 输入 + 编织 |
| **招募弹窗** | 玩家按 E 在阵亡者旁 | ✅ | "你愿意跟我走吗？" |
| **任务弹窗** | Quest 触发 | ✅ | 任务详情 + 接受/拒绝 |
| **Boss 战弹窗** | 进入 boss 房 | ✅ | Boss 名字 + "准备"按钮 |
| **聚落升级** | 升级时 | ❌ | 顶部 Toast + 音效 |
| **死亡界面** | 玩家死亡 | ✅ | "你死了" + "复活"按钮 |
| **教程提示** | 首次事件 | ❌ | 屏幕边缘提示 |
| **警告** | 关键决策 | ✅ | "选择不可逆" |

#### 弹窗结构

```
[深色画布覆盖 60% 屏幕（半透明 70%）]
+-------------------------------+
| [关闭按钮 X]                 |
|                               |
| [弹窗标题]                    |
|                               |
| [弹窗内容]                    |
|   - 文本 / UI 元素            |
|                               |
| [按钮 1]  [按钮 2]  [按钮 3] |
+-------------------------------+
```

#### 弹窗样式
- 背景：深色画布（0,0,0,0.7 alpha）+ 油画纹理 5%
- 边框：金色卢恩符文（1px）
- 圆角：4px
- 标题：衬线体 28px 金色
- 内容：衬线体 16px 米色
- 按钮：cyan 描边 + 悬停 cyan 填充

#### 弹窗动画
- 打开：0.5s 淡入
- 关闭：0.3s 淡出
- **不**用缩放/旋转
- 玩家按 Esc = 关闭（除死亡选择等不可关闭的）

### C.4 菜单（Menu）⭐

#### 菜单入口（参考 input-system.md）

| 键 | 菜单 | 是否暂停 |
|---|---|---|
| `Tab` / `I` | 物品栏 | ✅ |
| `C` | 聚落 | ✅ |
| `O` | 誓言 | ✅ |
| `E`（已用） | 英灵详情（在聚落窗口内） | n/a |
| `J` | 任务日志 | ✅ |
| `M` | 地图（v1.1） | ✅ |
| `Esc` | 暂停 / 设置 | ✅ |

#### 菜单架构（标签页 + 单页）

**物品栏**（最常用）：
- 左侧：背包 24 槽（参考 inventory.md）
- 右侧：装备栏（武器 / 工具 / 护甲 / 配件）
- 底部：物品详情

**聚落**（Living Hearth 落地）：
- 顶部：聚落 5 状态条（人口/士气/产出/资源/建筑）
- 中间：8 个英灵卡片（头像 + 名字 + Profession + 状态）
- 底部：聚落建筑（v1.0 简化：3 类 = 长屋/工坊/篝火）

**誓言**（Oath 落地）：
- 5 行（5 誓言）
- 每行：图标 + 名字 + 5 个里程碑方块（满/空）
- 点击誓言 → 展开 5 里程碑详情

**英灵详情**（在聚落窗口内打开）：
- 头部：英灵大头照 + 名字 + 年龄
- 中部：Profession 切换 + 工作效率
- 底部：关系 / 死亡倒计时（如果 willDie）

**任务日志**：
- 主线 / 支线 / 远征
- 滚动列表
- 任务详情：目标 / 进度 / 奖励

**暂停 / 设置**：
- 继续游戏
- 音量（主音量 / 音乐 / SFX / UI 音）
- 键位（v1.0 不支持重绑）
- 画面（亮度 / 字幕大小 / 颜色盲模式 v1.1）
- 退出到主菜单
- 退出游戏

#### 菜单样式
- 与弹窗一致（深色画布 + 卢恩符文边框）
- 选中项：cyan 描边
- 切换标签：底部 cyan 下划线

### C.5 Toast 通知 ⭐

#### Toast 类型

| 类型 | 显示时长 | 位置 | 颜色 |
|---|---|---|---|
| **资源拾取** | 2s | 屏幕右下 | 金色 |
| **等级提升** | 3s | 屏幕中央 | cyan |
| **任务完成** | 4s | 屏幕中央 | 金色 |
| **Boss 击杀** | 6s | 全屏（淡入） | 金色 |
| **错误提示** | 2s | 屏幕中央 | 红 |
| **教程提示** | 5s | 屏幕边缘（角落） | 米色 |
| **同伴状态** | 3s | 屏幕左下（聚落头像旁） | 灰 |

#### Toast 行为
- 多个 Toast 同时触发 → **堆叠**显示（最多 3 个同时）
- 鼠标悬停 → 暂停淡出
- 玩家按 Esc → 立即清空所有 Toast

#### Toast 样式
- 半透明深色背景（0,0,0,0.6）
- 16px 衬线体
- 图标（按类型）+ 文本
- 0.3s 淡入 + 显示 + 0.3s 淡出

### C.6 对话（Dialogue）

#### 与 `DialogueSO` 协同
- 触发：WorldEvent / Einherjar 招募死亡 / Oath 仪式 / 教程

- 背景：深色画布（0,0,0,0.85）

### C.10 主题切换（Day-Night 协同）

#### 主题参数
- **白天主题**：暖色调（米黄 / 淡金 / 浅米）
- **夜晚主题**：冷色调（深蓝 / 青 / 暗金）
- **Dawn/Dusk**：smoothstep 插值

#### 应用范围
- HUD 颜色
- 菜单背景色调
- 弹窗边框色
- 字体颜色
- **不**应用：玩家头像 / 物品图标（保持中性）

#### 性能
- 主题切换 = shader uniform 更新（< 1ms）
- 真实插值：1 秒（与 transitionVisualDurationSec 一致）

## D. Formulas

### D.1 HUD 性能预算
```csharp
float GetHUDFrameMs() {
  // 基础 HUD 渲染：< 4ms
  return healthBar.GetDrawMs() + staminaBar.GetDrawMs() + compass.GetDrawMs() + toolbar.GetDrawMs();
}
```

### D.2 弹窗淡入
```csharp
IEnumerator FadeIn(CanvasGroup group, float duration = 0.5f) {
  for (float t = 0; t < duration; t += Time.unscaledDeltaTime) {
    group.alpha = t / duration;
    yield return null;
  }
  group.alpha = 1f;
}
```

### D.3 主题插值
```csharp
Color4 GetThemeColor(Color4 dayColor, Color4 nightColor) {
  float t = TimeManager.GetDayNightProgress();  // 0=day, 1=night
  return Color4.Lerp(dayColor, nightColor, t);
}
```

### D.4 Toast 堆叠
```csharp
void ShowToast(Toast toast) {
  if (activeToasts.Count >= 3) {
    activeToasts[0].FadeOutImmediate();
  }
  activeToasts.Add(toast);
  toast.StartCoroutine(toast.FadeInOut(2f));
}
```

### D.5 UI 帧预算
```csharp
// 总预算 16ms（60 FPS）
// HUD: 4ms
// 弹窗/菜单: 8ms
// 全部 UI: 16ms
bool IsWithinBudget() {
  return UnityEngine.Profiling.Profiler.GetTotalAllocatedMemoryLong() < 16_000_000;
}
```

## E. Edge Cases

| 情况 | 处理 |
|---|---|
| 弹窗打开时新弹窗触发 | **排队**（关闭后立即开下一个） |
| 玩家在死亡选择时退出 | **不**保存选择，dying 状态持续 |
| Toast 风暴（10 个资源拾取同时） | **堆叠上限 3 个** + 合并（同类型 +N） |
| 玩家在菜单中时事件触发 | **暂停**事件处理，菜单关闭后处理 |
| 手柄 / 键鼠切换 | UI 自动切换 input map（参考 input-system.md） |
| 玩家 4K 屏幕 | UI 缩放（CanvasScaler） |
| 玩家窗口过小 | UI 缩放下限（不小于 1280×720） |
| 教程 30 条全部触发 | **不**重复触发（已显示过的不再显示） |
| 玩家死亡界面 | 不可关闭，必须选"复活"或"退出" |

## H. Acceptance Criteria

### AC-1: HUD 常驻
- **条件**：游戏开始
- **结果**：血量 / Stamina / God-Ember / 时间 / 工具栏 / 罗盘**全部**显示

### AC-2: 弹窗 Modal 行为
- **条件**：触发死亡选择 / 编织 / 招募弹窗
- **结果**：游戏暂停 + 弹窗显示 + 玩家必须选

### AC-3: 主题自动切换
- **条件**：Day-Night 转换
- **结果**：HUD 颜色 smoothstep 插值 1 秒

### AC-4: 菜单暂停
- **条件**：玩家按 Tab / I / Esc
- **结果**：游戏暂停 + 菜单显示

### AC-5: Toast 堆叠
- **条件**：10 个资源同时拾取
- **结果**：最多 3 个 Toast 同时显示，**第 4 个及之后合并为 "+N"**

### AC-6: 对话框
- **条件**：WorldEvent 触发
- **结果**：屏幕底部 1/3 显示头像 + 文本 + 选项

### AC-7: 罗盘兴趣点
- **条件**：玩家附近 200m 有 boss / 聚落
- **结果**：罗盘显示对应颜色标记

### AC-8: 教程触发
- **条件**：玩家首次编织
- **结果**：屏幕边缘出现教程提示 + 5 秒后淡出

### AC-9: 弹窗不可关闭
- **条件**：奥丁审判 / 死亡选择
- **结果**：Esc 不可关闭，必须看完/选

### AC-10: UI 性能
- **条件**：HUD + 菜单 + 弹窗全开
- **结果**：< 16ms / 帧

### AC-11: UI 风格统一
- **条件**：所有 UI 元素
- **结果**：深色画布 + 卢恩符文边框 + 衬线体

### AC-12: 键鼠 + 手柄支持
- **条件**：玩家切换 input device
- **结果**：UI 自动切换 input map
