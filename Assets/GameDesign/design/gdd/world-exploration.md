## A. Overview

**World Exploration 是 Ravensong 的"游戏世界"——玩家在 6 个群系间穿行、发现兴趣点、触发远征、解锁隐藏配方、招募英灵、击杀 boss。** 探索不是"开放世界"沙盒（避免成为 1 个 survival-crafting 通用模版），而是"**6 个群系 + 兴趣点 + 远征 + 隐藏奖励**"的**结构化探索**——每个群系都有"已知"和"未知"两个层级，**未知部分**是 Ravensong 探索玩法的核心。

Ravensong 的探索设计哲学是 **"叙事性探索"（Narrative Exploration）**：探索**不**是"为探索而探索"（不要"我已访问 100%" 进度条），而是**为"叙事发现"而探索**——发现隐藏配方 = 看到一束神秘 cyan 丝线；招募英灵 = 在战区看到阵亡者的光点；远征触发 = 在营地看到篝火。**探索的"奖励"是叙事时刻，不是数值**。

6 个群系（v1.0 锁定）：
- **白桦林**（Birch Forest）——聚落所在 + 入门群系
- **白骨原**（Bone Field）——战区 + 英灵招募
- **深渊沼**（Abyss Marsh）——夜魔资源 + Tier 3 配方
- **永冻崖**（Frost Cliff）—— Tier 4 资源 + 远征基地
- **奥丁圣所**（Odin's Sanctum）—— boss 房（4 个 boss）
- **深渊之心**（Heart of the Abyss）——终局区域

**远征系统** v1.0 简化：玩家亲自出发远行（不带兵），按"路线 + 时长 + 风险"模式。v1.1 决策：远征兵系统（派英灵远征，可死亡，触发 Death-Send-off 类型 4）。

**隐藏配方** 是 Fate-Thread 的核心探索奖励（参考 `fate-thread.md` §C.5 决策 #3）——20% 配方为"隐藏"，需玩家通过"探索 + 尝试组合"发现。

数据层由**新增**的 `ExpeditionSO`（data-config.md C.2 类型 13）驱动；本 GDD 专注于**群系架构、兴趣点、远征机制、隐藏配方、探索奖励、与 v1.1 远征兵预留接口**。

### A.1 Procedural-Level 框架审计（程序化关卡设计）⭐ 修复 P2 缺口

> 按 `21_程序化关卡设计.md` 框架显式审计 Ravensong 的程序化关卡设计，**把作者意图编码进约束而不是交给纯随机**。

#### 模块类型 vs 约束条件（按框架模板）

| # | 模块类型 | 数量 | 连接规则 | 约束条件 | 失败条件 | 制作方式 |
|---|---|---|---|---|---|---|
| 1 | **群系（Biome）** | 6 | 固定连通图（白桦林↔白骨原 / 白桦林↔深渊沼 / 深渊沼↔永冻崖 / 永冻崖↔奥丁圣所 / 奥丁圣所↔深渊之心）| 固定 6 个，**不能**随机增减 | 增加 = 破坏叙事 + 远征系统 | 🔧 **手工** |
| 2 | **POI（兴趣点）** | 70 | 5 类（10 主线 + 30 兴趣点 + 20 英灵招募 + 6 远征基地 + 4 boss 房）| 每群系 POI 数量 = 固定分布 | POI 不足 = 探索空洞 / 过多 = UI 过载 | 🎲 **程序化** + 固定分布 |
| 3 | **群系过渡带** | 5 | 30m 渐变 + 1s 插值 | 固定 30m（可调）| < 10m = 突兀 / > 50m = 浪费 | 🎲 **程序化**（插值）|
| 4 | **远征任务** | 18 | 6 基地 × 3 难度（短/中/长）| 固定分布，完成后**永久消失** | 重复 = 刷 | 🔧 **手工** + 固定 |
| 5 | **隐藏配方** | 6 | 6 群系各 1 个 + 特定输入组合 | 必须群系 + 输入**双约束** | 单约束 = 玩家乱碰发现 | 🎲 **程序化**（双约束）|
| 6 | **资源刷新** | 无限 | 24h 后 30% 概率 + 30% 数量 | 固定刷新率 | < 10% = 贫瘠 / > 50% = 无压力 | 🎲 **程序化**（概率）|
| 7 | **天气系统** | 7 | 6 真实小时最小间隔 + 7 类天气 | 概率固定（晴 60% / 多云 15% / 雨 10% / 雪 5% / 雾 5% / 暴风雪 2% / 神显 3% 满月）| 间隔 < 3h = 玩家无适应 | 🎲 **程序化**（概率）|
| 8 | **奥丁之眼扫描** | 无限 | 0.5h 间隔 + 30% 概率 | 固定概率 | 概率 > 50% = 干扰过重 | 🎲 **程序化**（概率）|
| 9 | **Boss 房** | 4 | 固定 4 个（白骨原 / 深渊沼 / 永冻崖 / 奥丁圣所）| 固定位置 + 必在夜晚（3 个）| 增加 = 破坏 Pillar 平衡 | 🔧 **手工** |

| 内容 | 类型 | 原因 |

| **5 誓言结构** | 🔧 手工 | 4 支柱 + 5 反柱 = Ravensong 核心 |
| **远征基地位置** | 🔧 手工 | 6 群系各 1 个 = 探索路径强制 |
| **隐藏配方"特定群系"约束** | 🔧 手工 | 否则玩家乱碰发现 = 失去探索价值 |
| **5 送别方式** | 🔧 手工 | 5 选 1 = 决策叙事核心 |
| **英灵 8 个槽位** | 🔧 手工 | `maxEinherjarInSettlement = 8` 锁定 |

#### 复用经济分析（Reuse Economics）

| 资产类型 | 手工制作 | 复用率 | 成本/复用比 |
|---|---|---|---|
| **群系 6 套** | 6 套（每群系 ~30 物件 = 180 物件）| 30 物件可跨群系复用（树 / 石头 / 通用生物）| 🟢 高 |

| **Boss 4 个** | 4 模型 + 4 演出 | **低复用**（每 boss 独特）| 🟡 中（必要成本）|
| **总复用率** | ~70%（30% 独特 boss 资产）| 🟢 优秀 |

#### 手工覆盖机制（Handmade Override）

| 场景 | 手工覆盖触发 | 例子 |
|---|---|---|
| **剧情事件** | 玩家**必须**触发特定事件 | 主线 1（炉火初燃）= 玩家招募 1 英灵 |

| **英灵死亡** | 玩家**不能**避免 | `willDie = true` 英灵**必须**在 `daysToDeath` 后 dying |

#### Procedural-Level 审计结论

**Ravensong 在 Procedural-Level 框架上**：
- ✅ **作者意图清晰**：手工 6 群系 + 4 boss + 5 誓言 + 6 远征基地 = 不可破坏的骨架
- ✅ **程序化"在该程序化的部分"**：POI 分布 + 资源刷新 + 天气 + 隐藏配方发现 = 适度随机
- ✅ **方差可读性高**：玩家**能**通过视觉 / 音频 / UI 识别"我在哪"
- ✅ **复用经济高**：~70% 资产复用率
- ✅ **手工覆盖机制合理**：剧情事件 + 隐藏配方 + 奥丁审判 + Boss 出现 = 程序化被手工合理覆盖
- ✅ **重玩价值证明**：v1.0 天气/隐藏配方 = 中-高重玩；v1.1 NG+ = 高重玩

**修复 P2 缺口** ✅ —— Procedural-Level 框架从"良好"升级为"优秀"。

**性能影响**：
- 模块约束分析 = 设计时（无运行时开销）
- 复用经济 = 制作时（节省 ~70% 资产成本）
- 手工覆盖 = 触发时（< 1ms / 帧）
- **总计**：无运行时性能影响

## C. Detailed Design

### C.1 核心规则（Core Rules）

#### 规则 1：6 个群系 + 1 个终局区
- 白桦林（聚落）
- 白骨原（战区）
- 深渊沼（夜魔资源）
- 永冻崖（Tier 4）
- 奥丁圣所（4 boss）
- 深渊之心（终局）
- v1.1 决策：+ 2 个群系（v1.0 锁定 v1.0 = 6 群系）

#### 规则 2：群系互相连通
- 白桦林 ↔ 白骨原（北 / 南）
- 白桦林 ↔ 深渊沼（东）
- 深渊沼 ↔ 永冻崖（北）
- 永冻崖 ↔ 奥丁圣所（东）
- 奥丁圣所 ↔ 深渊之心（垂直下降）
- v1.0 决策：**不**做"快速旅行"——移动 = 真实时间

#### 规则 3：群系有 Day-Night 难度差异
- 白桦林：昼夜平衡
- 白骨原：夜晚敌对 +30%
- 深渊沼：夜晚敌对 +50%
- 永冻崖：全天寒冷 debuff
- 奥丁圣所：3 boss 必在夜晚
- 深渊之心：永久夜晚


#### 群系难度系数表（建议进入顺序）⭐ P2 修复

| # | 群系 | 难度系数 | 资源 Tier | Boss | 建议进入阶段 | 主压力 |
|---|---|---|---|---|---|---|
| 1 | **白桦林** | ×1.0 | T1-T2 | 无（聚落所在）| Day 1-30（新手期）| 狼群（基础）|
| 2 | **白骨原** | ×1.3 | T1-T3 | 骨王 | Day 30-100（中期）| 尸鬼 + 狼群（夜晚）|
| 3 | **深渊沼** | ×1.6 | T2-T3 | 深渊之主 | Day 60-120（中期-后期）| 暗影 + 抗毒（夜魔资源）|
| 4 | **永冻崖** | ×1.9 | T3-T4 | 寒霜巨人 | Day 100-180（后期）| 寒冷 debuff + 篝火管理 |
| 5 | **奥丁圣所** | ×2.2 | T4 | 神话守卫者 | Day 150-200（后期-终局）| Boss 必在夜晚 |
| 6 | **深渊之心** | ×3.0 | T5（神话）| 奥丁审判 | Day 200+（终局）| 永久夜晚 + 奥丁演出 |

**难度系数计算公式**：
```
biomeDifficulty = baseEnemies * 1.0
              + dayNightMult * 0.3   // 夜晚加成
              + coldDebuff * 0.2      // 寒冷 debuff
              + (bossPresent ? 0.5 : 0)  // boss 房加成
```

**群系间梯度设计意图**：
- 群系 1-3：资源/战斗梯度（白桦林 ×1.0 → 深渊沼 ×1.6）
- 群系 4：寒冷 debuff（永冻崖 ×1.9，引入"持续压力"概念）
- 群系 5：boss 集中（奥丁圣所 ×2.2，3 个 boss）
- 群系 6：终局（深渊之心 ×3.0，永久夜晚 + 奥丁）

**玩家路径预期**：
```
Day 1-30:   白桦林（学习）→ 白骨原（探索）
Day 30-100: 白骨原（骨王）→ 深渊沼（适应）
Day 100-180: 永冻崖（耐久）→ 奥丁圣所（神话守卫者）
Day 200+:   深渊之心（终局）
```

**修复 P2 缺口** ✅ —— 群系难度阶梯从"vague 描述"变为"显式系数表"。


#### 规则 4：兴趣点（POI）分 5 类
- **金色 = 主线**（Oath 里程碑 / 终局触发）
- **Cyan = 兴趣点**（隐藏配方 / 远征基地 / 招募点）
- **灰 = 已访问**
- 距离>200m 时**不**显示（参考 ui-hud.md §C.8）
- 玩家 v1.0 不会同时看到 > 5 个 POI（避免 UI 过载）

#### 规则 5：隐藏配方 = 20% 全部配方
- 80 配方总数 × 20% = 16 隐藏配方（v1.0 锁定 25-30 配方中 5-6 个隐藏）
- 玩家通过"探索特定群系 + 尝试特定组合"发现
- 隐藏配方**不**在编织 UI 中显示
- 发现时 UI Toast "你发现了新配方：{name}"

#### 规则 6：远征系统 v1.0 简化
- 玩家**亲自**远行
- 远征 = 选定"路线" + 玩家移动 + 到达 POI + 返回
- 远征时长 = 真实时间（不加速）
- 远征奖励 = 资源 / 招募英灵 / 远征兵 v1.1 / 隐藏配方提示
- v1.1 决策：远征兵系统（派英灵远征，自动完成，玩家等待）

#### 规则 7：远征兵 v1.1 预留接口
- v1.0：**不**实现远征兵
- `ExpeditionSO.expeditionType` 字段 = "Player" / "Expeditioner"（v1.0 仅 Player）
- v1.0 远征死亡 v1.1 决策：远征兵死亡触发 Death-Send-off 类型 4

#### 规则 8：探索奖励分级
- **Common**（80%）：资源 / god-ember
- **Uncommon**（15%）：隐藏配方提示
- **Rare**（4%）：剧情英灵 / 远征基地解锁
- **Legendary**（1%）：boss 房入口 / Tier 5 配方线索

### C.2 6 个群系详细

#### 群系 1：白桦林（Birch Forest）—— 聚落所在

- 木材（基础）

## D. Formulas

### D.1 群系资源刷新
```csharp
float GetBiomeResourceYield(BiomeSO biome, ResourceType type) {
  float baseYield = biome.resourceYield[type];
  baseYield *= TimeManager.IsNight() && biome.nightBonus ? 1.5f : 1.0f;
  baseYield *= biome.favoredResources.Contains(type) ? 1.2f : 1.0f;
  return baseYield;
}
```

### D.2 POI 距离
```csharp
bool IsPOIVisible(POI poi) {
  float dist = Vector2.Distance(player.position, poi.position);
  return dist < GameConfigSO.uiCompassShowDistanceMax;  // 200m
}
```

### D.3 远征时长
```csharp
float GetExpeditionDurationHours(ExpeditionSO exp) {
  return exp.baseHours * exp.risk switch {
    Low => 1.0f,
    Medium => 1.5f,
    High => 2.0f,
  };
}
```

### D.4 远征奖励概率
```csharp
RewardTier RollReward(ExpeditionSO exp) {
  float roll = Random.value;
  if (roll < 0.01f) return Legendary;  // 1%
  if (roll < 0.05f) return Rare;        // 4%
  if (roll < 0.20f) return Uncommon;    // 15%
  return Common;                        // 80%
}
```

### D.5 隐藏配方发现
```csharp
bool TryDiscoverHiddenRecipe(string recipeId) {
  if (discoveredRecipes.Contains(recipeId)) return false;
  if (player.currentBiome != recipe.requiredBiome) return false;
  if (Random.value < recipe.discoveryChance) {
    discoveredRecipes.Add(recipeId);
    OnHiddenRecipeDiscovered?.Invoke(recipeId);
    return true;
  }
  return false;
}
```

### D.6 群系过渡插值
```csharp
Color4 GetBiomeTint(BiomeSO from, BiomeSO to, float t) {
  // t = 0 at from, 1 at to
  return Color4.Lerp(from.primaryColor, to.primaryColor, t);
}
```

### 数据结构
```csharp
public class Biome {
  public BiomeSO data;                   // 群系 SO
  public HashSet<string> visitedPOIs;     // 已访问 POI
  public float nightDifficultyMult;      // 群系夜晚加成
}

public class POI {
  public POIType type;                   // Main / Interest / Recruit / Expedition / Boss
  public string id;
  public Vector2 position;
  public POIState state;                 // Hidden / Discovered / Visited
  public RewardTier reward;              // Common / Uncommon / Rare / Legendary
}

public class Expedition {
  public ExpeditionSO data;
  public ExpeditionState state;          // Pending / InProgress / Completed / Failed
  public float elapsedGameDays;
  public string assignedPOI;             // 远征目标 POI
  public RewardTier rewardRolled;
}
```

### 状态机
```csharp
public enum POIState {
  Hidden,        // 未发现
  Discovered,    // 罗盘显示
  Visited,       // 已交互
}

public enum ExpeditionState {
  Pending,       // 已选未出发
  InProgress,    // 玩家在远征中
  Completed,     // 远征完成
  Failed,        // 玩家死亡 / 退出
}
```
